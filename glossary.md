# 📚 Media Buying Glossary

### Core Terms
- **mVAS (Mobile Value Added Services):** мобильные сервисы с подпиской (загрузка контента, антивирусы, подписки на видео/игры). 
- **1-Click Flow:** самый эффективный метод подписки, где пользователю достаточно нажать одну кнопку на лендинге.
- **RevShare (RS):** модель оплаты, при которой ты получаешь % от списаний абонента каждый день/месяц.
- **CPA (Cost Per Action):** разовая выплата за совершённое целевое действие (подписку).
- **Postback:** механизм передачи данных о конверсии из партнёрки в трекер.

### Traffic & Tracking
- **SmartCPM:** модель оплаты, где система сама оптимизирует цену за 1000 показов для выкупа лучшего трафика.
- **Popunder:** формат рекламы, который открывается в фоновой вкладке браузера.
- **Whitelist/Blacklist:** список площадок (Zone ID / Site ID), на которых реклама разрешена или запрещена.
- **ROI (Return on Investment):** показатель окупаемости ( (Доход - Расход) / Расход * 100% ).
