# Чек-лист проверки и запуска кампании

Универсальный чек-лист для контроля настроек перед стартом трафика и при аудите текущих кампаний.

---

## 1. Партнёрская сеть (CPA) и оффер
- [ ] Оффер активен, суточный лимит (капа) открыт.
- [ ] Условия целевого действия (1-Click, PIN, CPA/RS) соответствуют источнику.
- [ ] Разрешённые типы трафика проверены: Adult / Mainstream, тип устройств.
- [ ] Целевой мобильный оператор и тип соединения (Carrier / 3G/4G/5G) подтверждены.
- [ ] Ссылка потока содержит рабочий макрос для трекера (например, `cid={clickId}`).

---

## 2. Трекер (BeMob)
- [ ] Источник трафика и партнёрская сеть выбраны из шаблонов или проверены вручную.
- [ ] Входящие макросы источника передаются без ошибок (`[PRICE]`, `[SPOT_ID]`, `[OS_TYPE]`).
- [ ] Постбэк из партнёрки в трекер настроен и протестирован по тестовому переходу.
- [ ] Модель расхода соответствует источнику: Auto CPM для показов, CPV/CPC для кликов.
- [ ] Сплит-тест (если используется): веса офферов или лендингов выставлены корректно (например, 50/50).

---

## 3. Рекламная сеть (Traffic Source)
- [ ] Целевой URL взят из трекера (Campaign URL) со всеми обязательными токенами.
- [ ] Геотаргетинг: выбрана строго целевая страна (ISO: KZ / AZ / etc.).
- [ ] Таргетинг по устройствам: отключены десктоп и планшеты (если оффер строго под Mobile).
- [ ] Операционная система: Android / iOS разделены по кампаниям для чистоты сплита.
- [ ] Таргетинг по операторам: выбран нужный оператор (Carrier), Wi-Fi отключён при 1-Click Flow.
- [ ] Списки площадок: режим Whitelist / Blacklist переключён правильно.

---

## 4. Лимиты и финансовая безопасность
- [ ] **Суточный лимит бюджета (Daily limit):** выставлен минимально допустимый для теста ($1.00 – $2.00).
- [ ] **Почасовой лимит (Hourly limit):** проверен, чтобы не спутать суточный бюджет с часовым.
- [ ] Ограничение частоты показов (Frequency capping): выставлено (1 показ на 24 часа на 1 уникальный IP/User).
- [ ] Ставка (Bid / SmartCPM): не превышает комфортный тестовый коридор.

---

## 5. Первичный срез после запуска (1–2 часа)
- [ ] Проверить сходимость: клики в сетке = визиты в трекере (допустимое расхождение до 5–10%).
- [ ] Проверить передачу параметров площадок: в отчётах трекера видны реальные Zone/Spot ID.
- [ ] Проверить реальный расход в сетке: баланс списывается строго в рамках суточного лимита.
- [ ] Проверить привязку конверсий: при первом лиде postback корректно падает в трекер с выплатой.
